# Техническое задание: интерфейс отчетности SMSC CDR

## 1. Цель
Создать web-интерфейс отчетности для SMSC, который:
- загружает CDR-данные с двух серверов (`smsc1`, `smsc2`);
- складывает их в собственную БД;
- предоставляет фильтрацию по дате/времени, номеру и статусу;
- выводит агрегированный список записей из обоих источников;
- поддерживает выгрузку результатов в CSV.

## 2. Источники данных
Поддерживаемые источники:
- локальная папка с CDR-файлами (`mode: local`);
- SFTP-подключение к серверу (`mode: sftp`) по пути `/sftp/cdr/SMS`.

Формат CDR-строки (SMSC1):
`date,cdr_id,incoming_connection,outgoing_route,a_msisdn,a_msisdn_after_translation,b_msisdn,b_msisdn_after_translation,status`

## 3. Функциональные требования
1. Импорт CDR:
   - ручной запуск кнопкой "Import CDR from configured servers";
   - импорт из всех источников `config.yaml`;
   - дедупликация по (`cdr_id`, `source_server`).

2. Хранение:
   - SQLite БД в проекте;
   - таблица CDR-записей;
   - таблица журналов импортов (job history).

3. Фильтрация в UI:
   - `start datetime`;
   - `end datetime`;
   - `number` (поиск по A/B и translated A/B);
   - `status` (all/success/failed/error);
   - `source server`.

4. Отображение:
   - таблица записей CDR (до 1000 строк на экран);
   - таблица последних задач импорта.

5. Экспорт:
   - выгрузка текущей выборки в CSV.

## 4. Нефункциональные требования
- Простое локальное развертывание;
- Понятная конфигурация источников в `config.yaml`;
- Отказоустойчивость импорта: некорректные строки пропускаются;
- Логирование результата импорта (inserted/skipped/failed).

## 5. Архитектура
- Backend: Flask + SQLAlchemy;
- DB: SQLite (`cdr_reporting.db`);
- UI: серверный HTML (Jinja2);
- Ingestion service: парсер CDR + загрузка local/SFTP.

## 6. Структура проекта
- `app.py` — веб-приложение и роуты;
- `db.py` — модели и инициализация БД;
- `ingestion.py` — импорт CDR;
- `templates/index.html` — интерфейс;
- `config.yaml` — конфигурация источников;
- `sample_data/` — тестовые CDR-файлы.

## 7. Критерии приемки
- Кнопка импорта переносит CDR из двух источников в БД;
- В UI работают все фильтры (дата, номер, статус, сервер);
- Успешно отображаются записи с обоих серверов;
- Экспорт CSV выдает текущую фильтрованную выборку;
- История импортов отображает inserted/skipped и статус.
